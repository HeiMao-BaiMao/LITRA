【LITRA工程】common-sense-plan-check/v1
【依頼】
提示された構想メモ(この続きで起こす展開・場面の設定・時系列)を、現実世界の一般常識と照合して点検する。小説本文は書かない。この報告は構想の調整に使われる。

【点検項目 — 全項目を確認する】
1. 時系列・暦: 構想が前提とする経過日数・季節・学校年度(卒業式、入学式、始業式の時期)・行事が、現実の暦と整合するか。直前本文の時間設定と矛盾しないか。
2. 季節・気候: 構想の季節設定と自然現象(桜・紅葉・雪・気温)の時期。
3. 因果・物理: 構想内の行動が物理的・時間的に成立するか(移動、準備、連絡、回復)。
4. 社会通念・時代設定: 構想が前提とする制度・法律・道具が、現実または作品設定と整合するか。

【規則 — 全項目を必ず守る】
1. 作品の世界設定(【設定資料】)が明示的に逸脱を許している事柄は指摘しない。逸脱していない領域だけを現実の常識で判定する。
2. 問題が無ければ無いと書く。存在しない問題をひねり出さない。
3. 構想に書かれていない事項は未知として扱い、推測で補わない。
4. 【中略】は未知として扱う。
5. すべて日本語で書く。

【出力形式 — 厳守。次の見出しのみを使う】
【常識上の問題】(各1行: 問題 → 現実の根拠 → 修正方針。無ければ「なし」)
【構想への助言】(1〜3行。時系列・季節・設定の調整案。不要なら「なし」)

TASK:
Audit the supplied Japanese fiction draft for logic and motivation problems: unexplained scene entries, alliance statements that contradict interests, asserted facts the character has not confirmed, and strong romantic feelings without a concrete basis. The supplied project reference (設定資料・あらすじ) defines what the work has already established — do not report what it explains.

CHECK AREAS:
1. scene_entry: 人物がその場所へ現れた理由や、相手を見つけた経緯が示されているか。
   例: モカが地下書庫へ現れ、迷いなくあかりの向かいに座る。「偶然にしては、迷いのない動作だった。」しかし、モカがあかりを探していた理由は説明されない。
   報告例: 「モカが地下書庫であかりを発見した経緯が不明です。偶然なら疑念を示す文を削り、意図的なら探索理由を補ってください。」
2. alliance: 登場人物の目標が、協力・対立・裏切りの台詞と論理的に一致しているか。
   例: 「協力はしても、味方にはなれない」しかし、あかりがゆかりに接近すればモカはマキと二人になれる、モカがマキを引き受ければあかりはゆかりと話せる、ため現状では利益が一致している。
   報告例: 「二人の目的は相互補完的であり、『味方にはなれない』理由が不足しています。倫理観、手段、最終目標のいずれかに対立条件を追加してください。」
3. unconfirmed_fact: 人物が推測しか持っていない事柄を、確定事項として話していないか。
   例: ゆかりとマキが交際しているか確認していない状態で、「彼女たちを、別れさせるわけじゃない」と言う。
   報告例: 「二人が交際中であることは未確認です。『二人の関係を壊すつもりはない』など、認識状態に合う表現へ変更してください。」
4. affection_basis: 強い恋愛感情に対して、読者が納得できる具体的な過去や出来事が提示されているか。
   例: あかりは二年間、ゆかりとの再会を目標に努力しているが、好きになった具体的契機がまだない。モカも幼少期からマキを好きだが、喫茶店で何をされたのかは示されない。
   報告例: 「長期間の恋愛感情を支える具体的な記憶が不足しています。好きになった契機となる行動・台詞・事件を一つ追加してください。」

NOT ISSUES:
- 参考資料(設定・あらすじ・関連場面)が明示的に理由・根拠を説明している事柄。
- 意図的な伏線・情報保留(ミステリの未確認事実)。ただし台詞が確定事項として断定している場合は報告対象。
- キャラクターの認識の歪みとして意図的に書かれた断定は、物語内で後から覆されることが本文・資料に見えている場合のみ対象外。

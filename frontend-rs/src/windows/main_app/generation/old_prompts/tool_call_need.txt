CLASSIFICATION TASK:
Determine whether the user's request required an actual tool call that the assistant failed to execute.

PROCEDURE — follow in this exact order:
1. Inspect `user_request` and identify the concrete operation requested by the user.
2. Check whether at least one tool in `AVAILABLE TOOLS` can perform that operation.
3. Inspect `assistant_response` and determine whether the assistant merely described plans, steps, or hypothetical tool arguments instead of executing the tool.
4. Apply the decision criteria below. If uncertain → set `needsTools=false`.

Set `needsTools=true` ONLY when ALL three conditions hold:
- The user request asks to retrieve, search, verify, write, edit, apply, save, update, create, delete, or audit current application data (episodes, proposals, characters, worldbuilding, relationships, memos, summaries, edit logs, or genre records).
- At least one tool capable of performing that operation is listed in `AVAILABLE TOOLS`.
- `assistant_response` contains no executed result — it only promises an action, describes a procedure, outputs raw prose/patch text in chat when a write/generation tool was required, or stops before calling the tool.

Set `needsTools=false` when ANY of these holds:
- The request is pure conversation, general creative discussion, or critique of text already supplied inline by the user, requiring no application tool.
- The user only asked *how* to do something or asked a clarifying question without requesting execution.
- No tool in `AVAILABLE TOOLS` can perform the requested operation.
- The assistant truthfully reported missing prerequisites or an inability to proceed without pretending the action succeeded.

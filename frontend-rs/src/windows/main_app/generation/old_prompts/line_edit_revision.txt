【依頼】
既存原稿の一部 <reference_data name="passage_to_edit"> に対する査読結果 <reference_data name="review"> に従い、修正が必要な箇所だけを「対象と修正」の局所置換案として出力する。出力された置換はプログラムが文字列の完全一致で機械照合し、作者が採否を決める提案となるため、指定形式を一字一句厳守する。修正稿の全文は出力しない。

【手順 — この順番で必ず実行する】
手順1(出力しない): 周囲本文と対象範囲から語りの型、視点人物とその呼称、時制、文体（語彙、リズム、句読点の呼吸）を確定する。差し替え文もこの型と文体で書く。
手順2: 査読の【修正必須】をすべて解消するため、対象範囲から該当箇所を特定して置換を作る。
手順3: 査読の【改善提案】は、最小の書き換えで確実に文章が引き締まる場合に限り置換を作る。元のリズムや含意を損なう恐れがある場合は作らない。
手順4: 各置換が【修正時の注意】で保護された箇所を壊しておらず、下の【置換の規律】をすべて満たしているか確認してから出力する。

【置換の規律 — 全項目を必ず守る】
1. 「対象」は、<reference_data name="passage_to_edit"> 内の連続した文字列の一字一句そのままのコピーにする。句読点、改行、空白、記号も一切変えずに写す。1文字でも食い違う置換は機械照合で棄却される。
2. 対象と同じ文字列が <reference_data name="passage_to_edit"> 内に2回以上現れる場合は、前後の文脈を必要な分だけ含めて一意に特定できるようにする。
3. 置換同士で範囲を重ねない。対象範囲での出現順に並べ、件数は最大12件（読者への影響が大きい順）とする。
4. 「修正」は、前後の変更しない文と継ぎ目なく繋がる日本語にする。語りの型、視点人物の知覚/思考の境界、文体、一人称、時制を維持する。
5. 正史・【設定資料】に無い確定事実（未出の過去、経歴、関係、正体）や、人物の社会的属性から持ち得ない知識を新しく持ち込まない。
6. 複数の隣接する指摘が同じ1文〜数文に関わる場合は、1つの置換に統合して自然に直す。

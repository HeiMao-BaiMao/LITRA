【場面の現在状態 — 直前本文から抽出した事実カード】
下の <reference_data name="scene_state"> は、直前本文の末尾時点における場面の物理的・時間的・心理的状態を整理した記録である。
使い方 — 全項目を必ず守る:
1. 場所、時刻、同席者と不在者、各人物の姿勢・位置・所持品・負傷や身体状態・直前の行動をこのカードと一致させる。査読・改稿ではこのカードとの食い違いを【修正必須】として扱う。
2. カードは直前本文の要約である。万一カードと直前本文の記述が食い違う場合は、直前本文を正とする。
3. カードで「不明」とされた事項や記載のない過去を、既定の事実として書かない。
4. カードの箇条書き文言をそのまま小説本文に写さない。

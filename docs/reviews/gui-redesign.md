# GUI デザイン変更

バグ修正 commit `ef88c643fe2332213d5ec81f6fa28d32a99f3ea6` の後続として、既存 Rust/WASM UI の HTML と共有 CSS を変更する。新しい画面フレームワークへの移行や既存機能の削除は行わない。

## 方向性と変更

- 執筆画面を中心に、インク／ストーン系の暗色と控えめな紫で全画面の階層を統一。
- 「続きを書く」「書き直す」「講評」を原稿の直上へ移し、プロジェクト・取り込み・ジャンル・AI 設定を上部に分離。
- 原稿には余白と明朝系の文字組みを用い、作品構成とチャットはコンパクトな UI 用文字組みにする。外部フォントの取得は追加しない。
- モデル選択にプロバイダー／モデルの明示ラベルを追加し、設定画面の背景モデル・詳細項目を整理。
- フォーカスリング、本文／会話のアクセシブル名、ダイアログ見出し、動きを減らす設定を整備。
- 小さいウィンドウではチャットを画面外へ隠さず原稿の下へ配置。960px 以下で2列＋下段チャット、640px 以下で縦並びとし、折り畳み・別ウィンドウ・hidden 状態を維持する。

## 実施した検証

`python3 scripts/ui-preview/test_ui_contract.py -v` の4検査が成功。

- `index.html` の既存146 IDと38ボタン、`chat-window.html` の既存8 IDと3ボタンを保持。
- ID重複、存在しないlabel-for/aria-labelledby参照、label/formの不正な入れ子がない。
- CSS の括弧対応、hidden/detached/collapsed 契約、レスポンシブ・reduced-motion規則を静的検査。
- 主要な本文・補助文字・アクセント文字の定義色について、背景色との計算コントラストが4.5:1以上。
- `git diff --check` 成功。

## プレビューと検証できていない範囲

`scripts/ui-preview/` は実際のコンパイル済み WASM と、架空の作品・モデル情報を返すメモリー上の Tauri fixture を使う。変更前のHTML/CSSと変更後を同じバイナリで読み比べられる。empty/error/loading と viewport 切替を含む。

この実行環境のクラウドブラウザはlocalhostを `ERR_BLOCKED_BY_CLIENT` で拒否したため、スクリーンショット、実際の見た目、キーボード操作、リサイズ、入力、モーダル開閉、停止のブラウザ検証は未実施。制約の迂回・外部トンネル・公開ホスティングは行っていない。静的検査を画面確認済みとは扱わない。

対応環境では `scripts/ui-preview/README.md` に従って起動し、1440/1024/768/390px、主画面と分離チャット、プロジェクト未選択、設定、会話中の停止、折り畳みと別ウィンドウを確認してからリリースする。fixtureはOS資格情報、実AI接続、ネイティブウィンドウ管理の試験ではない。

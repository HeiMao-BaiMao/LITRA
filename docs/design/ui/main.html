      作品管理

      実アプリとは別の、画面案専用作品です。

        AI・アプリ設定

        役割別の選択状態を画面案で共有します。APIキーやOAuthには接続しません。

        保存と分離ウィンドウ

        画面案のデータはIndexedDBに保存します。別窓の前回配置は復元ボタンから一つずつ開けます。位置とサイズはブラウザが許す範囲です。

        実アプリへの接続が必要な機能

        AI生成・分析・ツール編集、実作品のインポート、WebDAV、OS資格情報、ネイティブ更新は未接続です。成功した表示は行いません。

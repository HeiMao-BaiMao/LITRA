# 機能・状態・分離の対応表

## 判定の範囲

この表は既存Rustフロントエンドと、`docs/design/ui/` の対話可能な画面案を対応づけます。**画面案の操作確認と製品機能の移行完了は別です。** Rust/WASM/Tauri本体と既存作品データは変更していません。

「画面案で対応」はフォーム・操作・専用ブラウザデータの実装を指します。「実操作確認」はFirefoxで通した代表経路であり、その行の全操作を網羅したという意味ではありません。

## ウィンドウと状態

既存の分離対象は [`windows/main_app/events.rs`](../../../frontend-rs/src/windows/main_app/events.rs) の `POPOUT_TARGETS` にある5種です。配置の永続化は [`src-tauri/src/window_state.rs`](../../../src-tauri/src/window_state.rs) にあります。

| 対象 | 状態の所属 | 画面案の分離先 |
|---|---|---|
| チャット | 作品ID。履歴・下書き・直接編集指定 | `panels.html?type=chat` |
| 要約 | 作品ID＋話ID。一行要約と要約は別フィールド | `panels.html?type=summary` |
| メモ | 作品ID＋話ID | `panels.html?type=memo` |
| 作品設定資料 | 作品ID。タブ・人物／世界観の選択・関係の範囲 | `panels.html?type=settings` |
| プロジェクトメモ | 作品ID＋メモID | `panels.html?type=project-memos` |
| ジャンルライブラリ | ジャンルID＋タブ・資料ID・分析ID | `genres.html` |
| ジャンル専用会話 | ジャンルID＋スレッドID | `panels.html?type=genre-chat&genreId=…` |

- 上記5種が同時に独立した分離先へ開くことを確認しました。以前の「1つの補助窓の3タブ」を分離対象の代わりにはしていません。
- SharedWorkerが唯一の画面案データ所有者です。保存完了前に成功を返さず、更新は作品・話・項目IDを明示して渡します。
- 分離操作はユーザー操作内で窓を確保し、保存と接続先の準備完了まで元画面を残します。戻す際も入力を確定してから元窓を閉じます。
- 人間関係の話別選択、説明、入力末尾のカーソル位置が、主画面→分離→再結合で復帰することを確認しました。
- 主画面を先に閉じても別窓で編集可能です。全画面終了後の再読込でデータと前回の別窓一覧を保持し、ジャンルライブラリの復元ボタンから実際に開き直しました。
- 通常の「別窓だけを閉じる」と「全画面を終了する」を区別します。主画面が残る状態で閉じた別窓は、次回自動復元の希望として残しません。
- 自動ポップアップ復元や正確な画面座標はブラウザ制約下では保証しません。復元ボタンと、ブラウザが許す位置・サイズを使います。

## 修正して確認した不具合

- ダイアログを閉じたとき、フォーム値の回収より先にPromiseが解決して登録が中断される順序を修正。原資料の登録、スレッド作成、テキスト添付の実操作で確認しました。
- 再結合時の再描画で未フォーカス項目の選択範囲が失われる問題を修正。フォーム再描画時の範囲保持、レイアウト通知の分離、主画面へのフォーカス復帰を行いました。
- 空の候補グループを繰り返し並べず、レビュー対象なしの表示に整理。採用済み知識を不必要に下へ押し出さない構成にしました。

## 未接続・未検証を区別する

未接続: 実作品形式の入出力、AIプロバイダ、WASM執筆コア、エージェントのツール実行・承認、OAuth・OS資格情報、WebDAV同期、Tauri固有のウィンドウAPI。画面案のJSON出力は実作品の保存形式ではありません。

未検証: すべてのCRUDの組合せ、削除に絡む全境界、IME実機入力、実ストレージ障害、ポップアップ拒否環境、スクリーンリーダー、全ブラウザ・全OSの互換性。これらの動作保証を、この画面案の確認結果からは導きません。

画面案データだけで確認した保存・操作を、製品データの移行や既存AI機能の維持が完了した証拠として扱わないでください。製品の実行境界は [アーキテクチャ](../browser-ui-architecture.md) を参照してください。
